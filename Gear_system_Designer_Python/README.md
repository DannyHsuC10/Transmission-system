# Python 齒輪設計工具

這個資料夾是 MATLAB `Gear_system_Designer` 的 Python 對應工具。它讀取 `data/tooth.csv`，計算太陽齒輪、兩種複合行星齒輪及內齒輪的幾何資料，並繪製齒輪配置、單齒輪齒形和齒輪系組合圖。

## 桌面介面

在本資料夾用含 Tkinter 的 Python 3 執行：

```powershell
python -m pip install -r requirements.txt
python gear_system_gui.py
```

左側會載入 `data/tooth.csv` 的預設值。修改參數後按「更新圖形」或 Enter，右側可切換「節圓配置」、「齒輪系組合」和「全組合」。「齒輪系組合」分開顯示兩層嚙合，「全組合」把兩層輪廓投影在同一張圖。圖形工具列可縮放、平移與儲存圖片。「還原預設」會恢復啟動時載入的參數，介面中的修改只套用到目前的預覽。

切到左側「單顆設計」後，選擇太陽輪、第一行星輪、第二行星輪或內齒圈。每種齒輪可各自調整齒數、齒頂與齒根倍率、齒間倍率及壓力角。外齒輪也可設定軸孔直徑。按「套用到齒輪系」後，右側「單顆預覽」會顯示齒形、幾何尺寸及旋轉按鈕，組合圖也會使用這組設定。齒根圓角倍率用來計算參考半徑，目前齒形仍以直線與圓弧接合。

模數由整個齒輪系共用。同一對嚙合齒輪須設定相同壓力角，且內齒圈齒數須等於太陽輪與兩級行星輪齒數的總和。若條件不符，組合圖會顯示原因，單顆預覽仍可查看。行星輪的設定會套用到該級的每一顆行星輪。

在左側「尋找組合」輸入模數、最大齒輪外廓、最低齒比、最小齒數與行星輪組數。按「搜尋組合」後，在右側「搜尋結果」勾選一列，再按「產生齒輪系」，即可把齒數、模數和行星輪組數帶入組合圖。搜尋沿用已套用的齒形與軸孔設定。

左側選取「尋找組合」時，右側只顯示「搜尋結果」。選取「單顆設計」時，右側只顯示「單顆預覽」和「詳細參數」。

在「單顆設計」開啟右側「詳細參數」，可查看目前選取齒輪的幾何數值。切換齒輪或套用設計後，表格會直接更新。徑節欄沿用 MATLAB 的 `2.54 / M`。

在「單顆設計」選擇格式並按「匯出齒輪」，可匯出目前已套用的齒輪。PNG 與 SVG 保存預覽圖，DXF 輸出毫米制的封閉輪廓，STEP 則依輸入厚度建立 3D 實體。內齒圈匯出 DXF 或 STEP 時須指定外徑。STEP 使用預覽取樣點建立漸開線樣條，齒頂、齒根圓弧和軸孔保留圓形幾何。STEP 匯出使用 Python 3.14 與 `requirements.txt` 所列的 Open CASCADE 套件。

候選依齒比由低到高排列，並列出外廓與行星輪幾何上限組數。搜尋使用兩支分析的中心距、齒比、行星輪公因數及相鄰行星輪間距條件。等角組裝相位按外嚙合與內嚙合的方向計算。外廓包括兩級行星輪的齒頂掃掠範圍和齒圈齒根圓，箱體壁厚與齒圈外壁需另外預留。齒比 `z` 為行星架固定時的齒比大小。齒圈固定、太陽輪輸入、行星架輸出時，減速比為 `1 + z`。

## 命令列

```powershell
python gear_system_designer.py
```

程式會在終端機逐一列印四種齒輪的計算資料，並開啟三個圖形視窗：行星齒輪系節圓配置圖、四種齒輪的個別齒形、齒輪系齒形組合圖。

指定另一份參數 CSV，或將圖存成 PNG：

```powershell
python gear_system_designer.py --data data\tooth.csv --save-dir output
```

參數 CSV 需有 `name`、`value` 欄位，並包含 `Ts`、`Tr`、`Tp1`、`Tp2`、`M`、`n`、`axle`。齒數和行星齒輪數必須是正整數，模數與軸徑必須大於零。

## 計算與繪圖內容

- 計算節圓、齒頂圓、齒根圓、基圓、齒高、工作深度、間隙、周節、齒厚、齒間、圓角、徑節、周節角和半周節角。
- 預設使用 20 度壓力角及標準全齒高參數。每顆齒輪的設定會用於計算漸開線齒面、齒頂弧、齒根弧、齒根至基圓的線段和軸孔。
- 複合行星齒輪依 MATLAB 範例共用中心，並以 `Rs + Rp1` 作為行星輪中心距；配置圖畫出各齒輪節圓，組合圖畫出全部齒形。
- 組合圖分開顯示兩個軸向平面。第一層顯示太陽輪與第一行星輪的外嚙合，第二層顯示第二行星輪與內齒圈的內嚙合。
- 節圓尺寸及中心配置沿用 MATLAB 範例。MATLAB 對齒圈也使用外齒輪繪圖函式。Python 改用標準漸開線極角，讓內齒的齒厚從齒根往齒頂縮小，並以外齒的實際齒中心對準內齒圈的齒槽。
- 相位校正以齒距和齒槽中心對齊為準，只驗證靜態齒形配置；不包含動態運動、干涉公差、接觸應力或強度分析。

預設 CSV 與 MATLAB 範例相同。要改齒輪規格，可直接修改 `data/tooth.csv`。
